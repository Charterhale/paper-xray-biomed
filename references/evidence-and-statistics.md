# 证据与统计：按主张核对

## 先区分三种声音

“直接观察”：某模型、某处理和某时间点，测量读出怎样变化。“作者解释”：作者认为这个变化意味着什么。“讲解者推断”：基于哪些来源提出了什么解释，是否可由其他原因产生。三者可以写在同一段里，但使用明确动词，读者不能误以为推断就是实测。

例如：“Fig. 3C 报告干预组标记物信号降低（直接结果）。作者把它解释为衰老状态减轻（作者解释）。如果同时存在细胞数量下降，平均信号可能受细胞选择影响；需核对计数与每细胞强度（待检验解释）。”具体哪种标记物、哪个细胞、哪个时间点必须来自实际论文。

## 证据指向不同主张

| 主张 | 对应证据要问什么 | 不应自动推出什么 |
|---|---|---|
| 表达/定位不同 | 检测层级、取样、归一化、组成、定量和重复 | 功能改变、作用方向 |
| X 与 Y 相关 | 时间顺序、混杂、选择、单位、模型 | X 导致 Y |
| 干预 X 改变 Z | 效率、特异性、毒性、分配、控制条件 | X 必经某个 Y |
| Y 对 X 的效应必要 | 干预 Y 时 X 的效应是否改变，模型/时点、Y 的其他作用 | Y 在所有情境下必要 |
| Y 足以影响 Z | 单独改变 Y 是否改变 Z，剂量/表达是否生理 | 自然病程必由 Y 导致 |
| X 通过 Y 影响 Z | 分步干预、救援/互作、时间/定位、替代路径 | 整条通路在人体已确证 |
| X 直接作用于 Y | 对应物理/生化实验、纯化/体系、特异性与位点 | 只有共定位或共表达即可证明 |
| 疾病相关细胞状态 | 供者设计、组织/病程与批次，差异与验证 | 细胞状态是疾病起因 |
| 诊断/预测可用 | 验证独立性、校准、阈值、流程、净获益 | 高 AUC 或高 SHAP = 临床可用/病因 |
| 治疗可转化 | 人体可达暴露、安全性、结局和试验环境 | 动物改善 = 人体疗效 |

这是按问题对准证据的地图，不是统一“证据分数”。患者观察数据对人体相关性有价值，动物干预对该模型因果比较有价值，两者不互相替代。

## 救援实验与互作

一个四组设计可以比较：对照、干预 X、改变 Y、干预 X + 改变 Y。双处理回到对照水平提示 Y 的改变可抵消 X 干预的表型；进一步要看 Y-only、毒性、表达量、剂量、时间和读出是否一致。双处理也可能用另一条通路补偿，不等于已经证明 X 直接调控 Y。

有“对照/干预 X/干预 X + 改变 Y”三组时，明确缺少的 Y-only 信息会限制什么，不声称救援完全无效。部分救援不应强行说成完全依赖或完全独立。必要性与充分性依赖具体系统、干预与读出，不以“有没有做过某实验”替代结果解释。

## 样本账本

先找设计中的独立主体，不把论文每个 `n` 填成同一个值。

| 层级 | 要记录的内容 | 常见陷阱 |
|---|---|---|
| 招募/分配 | 人、供者、动物、笼/集群等 | 分配单位与观察单位不同 |
| 生物材料 | 一个供者的多个组织、同动物双侧、独立培养 | 同主体内相关，配对被拆开 |
| 测量 | 切片、视野、细胞、spot、ROI、重复孔 | 多个测量冒充更多独立主体 |
| 技术重复 | 同一样本重复测定、同培养来源重复孔 | 测量精度提高不增加供者数 |
| 纳入分析 | 各比较保留的主体、缺失/排除 | 起始 N 与具体检验 N 不同 |

独立培养的含义也要核对：相同细胞系在不同天独立开展实验与同批次分孔不同，二者都不能替代多个生物供者。分层或混合模型可以利用下层观测，但应解释上层聚类怎样被处理。

最小证据表可按当前范围删去无关列：

| 主张/面板 | 对象与设计 | 组别/对照 | 独立 N 与配对/聚类 | 测量读出/单位 | 效应/区间 | 检验/调整 | 能支持的范围 | 来源/缺口 |
|---|---|---|---|---|---|---|---|---|

不要生成空表让读者填。可取得的内容填入，不明信息标 UNCLEAR 并说明缺失如何影响判断。

## 数值解释

- **效应与方向**：指出参考组、单位、时间点与是否调整。百分比、百分点、fold change、log2FC 不是同一种单位。
- **置信区间**：解释估计精度及区间覆盖哪些有实质意义的效应；不说“参数有 95% 概率落在这一次频率学区间”。
- **P 值**：依据指定模型/零假设解释，不叫“零假设为真的概率”或“结果是偶然的概率”。统计显著不代表大效应、机制正确或临床有用。
- **阴性结果**：未显著可能来自效应小、不精确或设计限制；不能自动判定没有作用。等效/非劣需要相应目标、界值与区间。
- **误差棒**：核对 SD、SEM、CI 或其他定义；不知道就写未知。不能只看误差棒是否重叠确定检验结果。
- **亚组**：某亚组显著、另一亚组不显著不等于两亚组不同；核对交互、预设性和多重比较。
- **重复测量**：同主体多个时间点、左右侧或组织需要相应依赖结构，不能当独立组。
- **多重检验**：区分未校正 P 与 FDR/校正 P，核对调整的检验家族；“所有显著基因”应带阈值与数据层，探索性结果保留其状态。
- **混杂和缺失**：给实际调整集、缺失比例与处理；“多因素校正”不能笼统解释成无混杂。

## 临床效应的小算例

只有论文报告或明确教学数据允许计算。二分类风险 $p_C$ 和 $p_T$ 的时间窗、结局与分母一致时：$RR=p_T/p_C$，风险差 $RD=p_T-p_C$。对不良结局，治疗风险较低时 $ARR=p_C-p_T$；$NNT=1/ARR$（ARR 用比例，通常向上取整），并说明随访期、估计不确定性与适用人群。不要跨研究凑分母，也不要把 HR 直接代入这套公式。

OR 与 RR 区别：odds 为 $p/(1-p)$。结局常见时 OR 不可随意当 RR。HR 比较瞬时风险率，并不直接给某随访时点的累积风险降低；需要模型假设与曲线信息。

## 标志物和图像的边界

单个炎症/衰老/细胞死亡标记不应自动代替完整过程证据。指标是否特异、位于何种材料、采用哪个定量和是否有功能佐证，都要按论文事实说明。比如自噬相关蛋白的静态水平与通量不同；NET 相关标记与完整 NET 形成不同；表达、磷酸化、酶活和代谢物丰度不是同一个层面的读出。不要自动要求某个固定实验组合，只说当前主张需要区分哪些可能。

图像如无可读比例尺、门控、原始 blot 或定量说明，明确可解释范围。染色面积增大可能来自细胞数、强度或结构改变；组成与单细胞状态要分开。没有原始图不能断言剪辑造假，也不能说已排除图像问题。

## 计算预测与可重复性

特征选择、插补、标准化、调参若使用验证/测试信息，会影响性能的独立性。核对拆分单位以及公共数据的重叠，不只看随机种子。验证一份公开代码能帮助核对实现；代码可用不等于数据可得、结果可重复或生物结论成立。

模型解释依赖模型与输入分布。SHAP 可为正/负且在不同输出尺度上含义不同，相关基因会分配或替代贡献；应解释具体设定。预测通讯、富集和轨迹是候选证据，功能验证缺失时写假说。

遇到数据/样本/方法冲突，指出哪条主张因此需要 STOP / REVIEW REQUIRED，继续讲解不依赖该冲突的部分。不要因为一个字段不明就停止所有阅读，也不要为了完成故事猜测关键参数。
