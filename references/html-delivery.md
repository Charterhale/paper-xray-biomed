# HTML 精读交付

用户要求网页/HTML/交互时使用。正文证据标准不因形式改变，用户只要单图讲解时范围仍限于单图。HTML 是解释载体，不是自动对外发布的授权。

## 内容与版式

默认一个本地可打开的 HTML 文件，内联样式和脚本；长文用目录、锚点与自然段，表格和图随论证出现。大屏可用左侧目录加正文，小屏切为单栏与可展开目录；正文行宽适中，图表可横向滚动，不能缩成读不清的小字。

提供亮/暗主题，初始跟随系统，可手动切换。暖纸白背景、深灰正文、克制强调色可以延续原版风格；颜色用于稳定区分组别或证据角色，不把“病例/对照”和“确定/不确定”混成同一含义。每张图有可见图例与非颜色线索，保留科学标注，不照搬机器学习架构框的固定宽度。

信息块明确来源、材料可用程度和研究类型。重要结论可点击跳到对应 Figure/面板或 Table；自绘机制图区分实测、模型内推断和未验证假说，图注写出边的含义。不要把实线/虚线当作未经说明的统一因果语法。

## 交互选择

只为一个明确疑问增加交互，组件可按论文选择，不凑数量：

- **证据链切换**：选一个结论，突出对应实验、对照、直接结果与剩余缺口。
- **逐面板阅读**：选 Fig. 2A/2B 等，显示真实图或可核验定位，以及“设计—结果—解释”。
- **四组对照推演**：分步揭示对照、单干预和双干预如何改变解释，构造值醒目标教学示意。
- **样本层级**：供者 → 样本 → 切片/细胞，展示独立主体数与测量数的区别。
- **绝对风险示例**：改变教学假定的基线风险，比较 RR 与风险差；仅在相应公式和条件清楚时使用。
- **方法步骤**：选一个测量或分析步骤，显示输入、输出和具体假设；不虚构实际测量值。

不要以真实论文名呈现未验证的疗效模拟。教学滑块必须说明假设和未验证状态，不能产生看似临床决策的个体建议。每个交互初始即有内容，关闭脚本时核心解释仍可读。

## 图片、公式与本地可用性

原图只引用实际取得的材料，注明来源和面板；局部放大注明裁切，不改变科学含义。优先将可分享的必要图片内嵌或配套保存，不能引用本机不存在的路径。不得为了视觉效果补画“原始 blot”、虚构显微图或用示意替代实际观测。

数学公式少时可用可访问的文字/MathML；需要 KaTeX 等渲染器时使用环境中可取得的资源，不默认为网络依赖已可离线。若使用 CDN，正文与交互离线仍可读，并明确公式渲染依赖网络或有何回退，不能称完全离线自包含。不要为了这项交付安装不必要的框架。

设置按钮和输入控件的标签、键盘操作与焦点状态；不依赖悬停才能看到关键结果。响应 reduced-motion，不自动播放动画；文本对比度、表头与表格说明可读。

## 实际验证

完成后用可用的浏览器/预览工具检查首屏、全部组件、目录、窄屏、亮暗主题、边界输入与无网络时的可读性。检查运行错误、NaN、空图、单位/分母和数据来源是否在互动后仍正确。能检查脚本语法时做语法检查；语法通过不等于浏览器运行通过。

没有浏览器工具时检查结构和计算，明确“未做浏览器运行验证”，不能写“所有交互已验证”。如果宿主能打开本地文件则打开交付结果；按实际验证程度报告，而不是把预期行为当完成状态。
